## 摘要
本工作研究折扣一般和马尔可夫博弈中的彻底解耦学习。假设“PPAD的ETH”，我们证明对于每个固定的折扣因子，当玩家在去中心化设置中独立学习时，不存在多项式时间算法来计算折扣一般和马尔可夫博弈中反多项式精度的粗相关均衡。作为对该困难结果的补充，我们提供了似乎是首个彻底解耦算法，在不强加任何结构性限制的情况下，对折扣一般和马尔可夫博弈中的粗相关均衡具有次指数收敛保证。我们的算法是乐观镜像下降的一种分层变体，采用针对多智能体设置量身定制的递增步长方案。最后，我们开发了上述算法的全反馈和部分反馈版本，并为每种情况建立了次指数收敛保证。

## Abstract
In this work, we study radically uncoupled learning in discounted general-sum Markov games. Assuming ``$\mathsf{ETH}$ for $\mathsf{PPAD}$", we show that, for every fixed discount factor, there is no polynomial-time algorithm for computing inverse-polynomially accurate coarse correlated equilibria in discounted general-sum Markov games when players learn independently in decentralized settings. Complementing this hardness result, we provide what appears to be the first \emph{radically uncoupled} algorithm with sub-exponential convergence guarantees to coarse correlated equilibria in discounted general-sum Markov games without imposing any structural restrictions on the game. Our algorithm is a \emph{layered} variant of optimistic mirror descent with an increasing step-size schedule tailored to the multi-agent setting. Finally, we develop both full-feedback and partial feedback versions of the aforementioned algorithm and establish sub-exponential convergence guarantees for each case.

## 1. 论文的核心问题与整体含义

本论文研究**折扣一般和马尔可夫博弈（discounted general-sum Markov games）中的彻底解耦学习（radically uncoupled learning）**问题，属于多智能体强化学习（MARL）的理论研究。其核心动机来自以下背景：

- 在标准**正则形式博弈**中，独立学习与均衡计算的关系已经比较清楚：若所有玩家具有消失的外部遗憾（external regret），则平均策略经验分布收敛到粗相关均衡（CCE）；若具有消失的交换遗憾（swap regret），则收敛到相关均衡（CE）。
- 然而在**马尔可夫博弈**中，这一对应关系远未建立。核心障碍在于：玩家的单方面策略偏离不仅影响即时损失，还会改变未来状态的分布，而这些"历史占用权重"对学习者而言是未知且时变的。现有的正向结果大多依赖**协调机制、共享随机性、通信或事后处理**，不满足彻底解耦的信息限制。
- 已有负向结果表明，在有限时域一般和马尔可夫博弈中，任何获得无遗憾性质的独立学习算法都是PPAD-难的。

因此，作者提出研究问题：**在彻底解耦信息结构下，是否存在（准）高效的独立学习算法来逼近折扣马尔可夫博弈中的均衡？**

论文的整体含义是：在"PPAD的ETH"假设下，证明折扣马尔可夫博弈中计算反多项式精度CCE不存在多项式时间算法（即存在根本性的计算障碍）；同时，作为补充，首次提出一种**无结构限制**的彻底解耦算法，实现**次指数收敛**保证，从而刻画了该问题的计算复杂性上下界之间的"准多项式"地带。

## 2. 论文提出的方法论

论文的核心方法论是**分层乐观在线镜像下降（Layered Optimistic Online Mirror Descent, OOMD）算法**，并辅以**截断-扩展（truncation-extension）**技术从有限时域转移到折扣马尔可夫博弈。

### 2.1 全反馈机制下的核心算法（Algorithm 1）

**算法结构**：在每个玩家-状态-层三元组$(i, s, h)$上执行局部策略更新，使用上一轮产生的状态-动作价值向量作为反馈。

**两个关键设计**：

1. **平滑熵正则化器（smoothed entropy regularizer）**：
   \[
   \Psi_i(x) = \sum_{a \in A_i} (x(a) + \lambda_i)\log(x(a) + \lambda_i)
   \]
   其中$\lambda_i = 1/|A_i|$，对应的Bregman散度$D_i(x, y)$在整个单纯形上有界，且上界随动作集大小仅对数增长。该"固定分享"（fixed-share）式的平滑（借鉴自Herbster \& Warmuth [1998]和Salem et al. [2024]，但用途不同）使得算法可以比较器为任意分布$\mu_i^h(\cdot|\tau_h)$，同时保证有界Bregman直径$B_i = 2\log(|A_i|+1)$。

2. **递增层间步长方案（increasing layer-wise step-size schedule）**：
   \[
   \alpha_h = \frac{3(H-h)+1}{3H+1}, \quad \eta_h = \eta_0 T^{-\alpha_h}
   \]
   较早层使用较小学习率（策略移动缓慢），较晚层使用较大学习率（下游快速适应）。这种嵌套的时间尺度分离使历史占用权重的漂移可控，是算法能够处理马尔可夫博弈动态性的关键。

**收敛率**：算法达到$O(T^{-3/(3H+1)})$近似的CCE，其中$H$为时域长度（Theorem 1）。

**证明核心步骤**（三层分解）：
- 将马尔可夫博弈遗憾重写为**局部加权遗憾项之和**（Lemma 12）；
- 控制**历史权重漂移**$TV^{i,\mu}_h \leq 3m\bar{\rho}HT\sum_{\ell<h}\eta_\ell$（Lemma 9）和**Q函数变化**$O(\eta_H^2)$（Lemma 11）；
- 步长方案使各项误差同阶平衡。

### 2.2 部分反馈机制下的算法（Algorithm 2）

在部分反馈设置下，玩家只能观测自己的轨迹。算法做出两点修改：

- **探索下限**：镜像下降在受限单纯形$\Delta_\zeta^i = \{x : x(a_i) \geq \zeta/|A_i|\}$上进行，确保每个动作有最小探索概率；
- **分块估计**：将$B$个独立回合组成一个块，块内重复同一策略，利用轨迹数据估计Q函数（访问计数$N^{k,i}(s,a^i)$的样本均值）。

**可达性假设**（Definition 7）：要求在任何满足探索下限的马尔可夫策略下，所有状态-动作对的占用概率至少为$\kappa$，保证Q函数估计的均匀精度。

其收敛保证（Theorem 2）在保持相同的指数-时域依赖的同时，增加了来自探索和估计的多项式开销。

### 2.3 折扣马尔可夫博弈的扩展（Theorem 3）

**截断-扩展原则**：由于折扣因子$\gamma < 1$使未来层的贡献几何衰减，只需控制前$L$层即可逼近原折扣目标，误差上界为$\tau_{L,\bar{H}}(\gamma) \leq \gamma^L/(1-\gamma)$。

- 选择截断长度$L_\varepsilon = \min\{\bar{H}, H_\gamma^\varepsilon\}$，其中$H_\gamma^\varepsilon = \lceil \log(2(1-\gamma)\varepsilon)/\log(1/\gamma) \rceil = O(\log(1/\varepsilon))$；
- 在截断博弈上运行有限时域算法，使有限时域遗憾$\leq \varepsilon/2$，截断误差$\leq \varepsilon/2$，合成得到原折扣博弈的$\varepsilon$-近似CCE。

**关键效果**：由于$L_\varepsilon$只随$\log(1/\varepsilon)$增长，原本随$H$指数依赖的有限时域遗憾指数被压缩为**准多项式**依赖（Corollaries 1和2），从而获得次指数收敛保证。

## 6. 论文的主要结论与发现

1. **计算复杂度下界（Theorem 5, Corollary 3）**：假设"PPAD的ETH"，对于每个固定折扣因子$\gamma \in (0,1)\cap\mathbb{Q}$和任意多项式支撑界，在有限时域或无限时域折扣一般和马尔可夫博弈中，不存在多项式时间算法计算稀疏近似CCE。这意味着**准多项式时间算法是当前认知下所能期望的最佳结果**。

2. **全反馈次指数上界（Theorem 1, Corollary 1）**：分层平滑熵乐观镜像下降算法在有限时域一般和马尔可夫博弈中达到$O(T^{-3/(3H+1)})$遗憾率，对应CCE收敛；通过截断扩展，在折扣设置下实现**准多项式时间**和**准多项式样本复杂度**。

3. **部分反馈扩展（Theorem 2, Corollary 2）**：在$(\kappa, \zeta)$-可达性假设下，分块估计版本的算法保留相同的次指数收敛保证，增加来自探索和估计的多项式开销。

4. **数值验证**：在四个有限时域博弈和折扣LQ基准上，CCE间隙（或值误差）均随回合数递减，验证了理论收敛性。

## 8. 不足与局限

### 8.1 理论层面

- **次指数与多项式之间的间隙未闭合**：论文证明了下界为多项式时间不可行、上界为准多项式时间可行，但精确的计算复杂度（是否真的需要准多项式时间）仍是一个未解决的问题；
- **可达性假设限制了部分反馈算法的适用性**：$(\kappa, \zeta)$-可达性要求所有状态在探索策略下都有正概率被访问，这在状态空间较大或存在难以到达状态的博弈中可能不成立；
- **常数因子对$H$的指数依赖**：尽管在折扣设置下通过截断将依赖压缩为准多项式，但有限时域遗憾中的常数$C_{\text{SE}}^*$对时域$H$本身是多项式增长（如$H^7$项），当$H$较大时实际收敛可能较慢；
- **算法仅针对CCE而非更精细的CE或NE**：粗相关均衡是较弱的均衡概念，对于追求更强均衡概念的场景可能不够用；
- **信息结构假设严格**：算法要求每个玩家在每个状态的所有动作上都能获得Q函数估计（全反馈）或足够的轨迹采样（部分反馈），这在连续状态/动作空间或高维观测下难以直接实现。

- **统计检验不足**：全反馈实验的收敛曲线未报告多次运行的标准差或置信区间，部分反馈实验虽报告20次运行的均值与标准差，但未进行显著性检验，难以判断收敛差异的统计可靠性；  
- **LQ基准实验设置较为简化**：仅报告与闭式解的值误差，未报告CCE间隙或均衡策略偏差，且未说明重复次数，削弱了该实验对算法均衡收敛性质的支持力度；  
- **缺乏对超参数敏感性的分析**：算法中的学习率$\eta_0$、块大小$B$、探索下限$\zeta$等关键参数均取固定值，未讨论不同参数设置对收敛速度和最终精度的影响，不利于评估算法的鲁棒性。

总体而言，实验部分对理论结果提供了一定支撑，但受限于规模、对比和统计检验的不足，其实证说服力有限。
