## 摘要
类人私人聊天需要的不仅仅是流畅的回复生成：系统必须保持人设、关系、记忆、有限知识、特定媒介的时机感以及连贯的多轮对话弧线。我们提出了 AnthroDial，一个将拟人化对话表述为系统架构、可执行评估与诊断式对齐的联合问题的闭环框架。它结合了（1）带有角色与人设场景卡片、长期记忆、虚拟时间和单次草稿消息决策的角色条件化对话调度运行环境；（2）一个包含 L0 有效性门槛、五个单轮维度和五个对话级维度的可执行基准；以及（3）一个后训练流水线，该流水线筛选了 16,436 个调度决策示例用于监督微调（SFT），并使用包含认知诊断、最近发展区（ZPD）感知的奖励进行 GRPO。该奖励为每个行为维度维护卡尔曼滤波的能力估计，对能力缺陷更大的维度赋予更高权重，并用 rollout 分数作为任务级 ZPD 匹配，将优化聚焦于可学习的薄弱技能。在一个包含 55 个角色、50 个场景、50 个人设-场景绑定以及每个模型 100 个角色条件化案例的基准上，我们评估了 16 个系统，覆盖前沿基线、开放模型、思考/非思考变体以及 SFT/RL 消融实验。最强的未训练基线达到了 32.00% 的严格准确率，而 Qwen3.6-27B-SFT+RL 达到了 39.00% 的严格准确率和 98.5 的总体分数。在 9B 非思考设置下，SFT 和 RL 将严格准确率从 0.00% 提升至 13.00% 和 18.37%。这些结果表明，当生成、评估和奖励塑造共享相同的行为维度时，拟人化对话会从中受益。

## Abstract
Human-like private chat requires more than fluent response generation: a system must preserve persona, relationship, memory, bounded knowledge, medium-specific timing, and a coherent multi-turn arc. We present AnthroDial, a closed-loop framework that formulates anthropomorphic dialogue as a joint problem of system architecture, executable evaluation, and diagnostic alignment. It combines (1) a role-conditioned scheduled dialogue runtime with persona and scenario cards, long-term memory, virtual time, and single-draft message decisions; (2) an executable benchmark with an L0 validity gate, five per-turn dimensions, and five dialogue-level dimensions; and (3) a post-training pipeline that filters 16,436 scheduled-decision examples for SFT and applies GRPO with a cognitive-diagnostic, ZPD-aware reward. The reward maintains Kalman-filtered capability estimates for each behavioral dimension, upweights dimensions with larger capability deficits, and uses rollout scores as task-level ZPD matches to focus optimization on learnable weak skills. On a benchmark with 55 personas, 50 scenarios, 50 persona-scenario bindings, and 100 role-conditioned cases per model, we evaluate 16 systems spanning frontier baselines, open models, thinking/no-think variants, and SFT/RL ablations. The strongest non-trained baseline reaches 32.00% strict ACC, while Qwen3.6-27B-SFT+RL reaches 39.00% strict ACC and a 98.5 overall score. In the 9B no-think setting, SFT and RL improve strict ACC from 0.00% to 13.00% and 18.37%. These results show that anthropomorphic dialogue benefits when generation, evaluation, and reward shaping share the same behavioral dimensions.

### 2. 论文提出的方法论

论文提出了名为 **AnthroDial** 的闭环框架，核心在于将人设、记忆、时机和对话弧线等要素都外化为可生成、可评估、可优化的明确模块。

- **核心思想**：将拟人对话建模为“角色条件调度对话”问题，并将“生成-评估-后训练”三个环节紧密耦合，使用同一套行为评估维度来指导整个闭环。

- **关键技术细节**
    - **角色条件化的对话运行时**:
        - **状态表示**: 每个说话者的决策状态 `x` 由以下部分构成：渲染后的人设/场景卡片、伙伴特异性的长期记忆、压缩的对话摘要、最近的逐字窗口、可能存在的被打断的草稿、以及当前虚拟时间。
        - **单次草稿决策与调度**: 模型在每个决策点输出一个草稿 `d = (文本, 延迟, 结束) `，而非一个简单的回复。系统维护一个草稿缓冲区，调度器根据虚拟时间发送最早到期的消息，实现了多消息连续发送、消息中断、草稿废弃、自然沉默和对话终结等机制。
    - **可执行评估基准**:
        - **L0 有效性门槛**: 用一个确定性的扫描器剔除存在致命错误的对话（如暴露AI身份、违反纯文本媒介、硬性事实矛盾）。
        - **多维度评分**: 对通过L0的对话进行评分，包含5个**单轮维度**（如聊天自然度、信息密度、人设一致性）和5个**对话级维度**（如事实一致性、场景契合度、社交情绪契合度、主动性、对话弧线）。
    - **闭环后训练对齐管道**:
        - **监督微调 (SFT)**: 筛选高质量（通过L0，且分数极高）的 16,436 个调度决策示例，训练模型生成包含“内容、延迟、结束”的决策体。
        - **CDT-ZPD 引导的 GRPO 算法**: 这是论文的核心**算法贡献**，旨在将优化压力导向模型薄弱的行为维度。其奖励信号由三部分组成：
            1.  **卡尔曼滤波能力估计 (CDT)**: 为10个行为维度维护一个动态的能力估计值 `θ_k`，通过卡尔曼滤波器，用每批 rollout 的分数来平滑地更新它。
            2.  **能力缺陷加权**: 对于能力估计值 `θ_k` 较低的维度，计算一个更强的奖励乘数 `d_k = 1.20 - θ_k`，以增加其优化权重。
            3.  **最近发展区匹配 (ZPD)**: 对于当前生成的对话 `D`，用其在维度 `k` 上的得分 `s_k(D)` 作为该任务“可达成性”的经验估计，并计算一个 ZPD 匹配因子 `ω_k(D)`。当任务难度接近模型当前能力时，该因子最大。这确保了奖励聚焦于模型可学习的薄弱技能，而非惩罚远超当前能力的失败。

### 6. 论文的主要结论与发现

- **闭环框架有效**: 提出的 AnthroDial 框架能成功提升对话系统的拟人化水平。其中，Qwen3.6-27B-SFT+RL 模型在严格准确率（39.00%）和总分（98.5）上均显著超越了最强的未训练基线模型（Gemini-3.5-Flash，32.00%）。
- **后训练至关重要**: 单纯的测试时思考远不够。SFT和RL能赋予模型超越推理模式本身的拟人行为。
- **9B 小模型路径可行**: 在无思考模式下，通过SFT和RL，可以将小模型的严格准确率从0%提升至18.37%，甚至超过了更大的未训练的27B思考模式模型，证明了该管线可向高效的、更低延迟的部署场景迁移。

- **共享行为维度是核心**: 生成、评估和奖励塑造统一使用10个行为维度，是该框架有效性的关键。
- **硬性场景依然存在**: 即使在连续评分很高的情况下，一些模型在特定类别（如科技、财经）的严格准确率依然为0，表明这些场景存在难以通过的“硬性”约束。

### 7. 优点

- **系统化与独创性设计**: 将拟人对话从“风格问题”提升为一项包含架构、评估和对齐的**系统工程**。单次草稿调度器设计巧妙，将时机、打断、沉默等模糊概念外化为可执行的决策。
- **深刻且创新的奖励机制 (CDT-ZPD):** 这是一种非常先进的强化学习奖励层设计。它不依赖模糊的整体分数，而是通过卡尔曼滤波动态诊断模型能力，并利用ZPD思想将优化压力精准分配到“当前可学习的薄弱技能”上，避免了无效优化和“高分低能”的问题。
- **极致的闭环透明度与可审计性**: 整个流程生成的不仅是对话，还有完整的决策日志、评估痕迹和失败原因。这使得模型的每一次失败都可被追溯、分类和修复，为数据筛选和技能演进提供了坚实基础。
- **多维度、深层次的评估体系**: L0有效性门槛+双层级（单轮/全局）+多维度（10个）的评估，不仅提供了更全面、细致的模型能力画像，也深刻揭示了“局部好不等于全局好”这一关键洞察。

### 8. 不足与局限

- **算力开销未知**: 完全未提及此类复杂系统训练和推理的计算成本，使其实际落地的可行性不透明。
- **媒介文化特定性**: 当前基准完全围绕**中文私人微信式聊天**构建，其评估标准（如“WeChat naturalness”）可能无法直接迁移到其他语言或聊天媒介。
- **裁判模型偏差风险**: 使用Qwen系列的模型作为裁判来评估同系列模型，存在一定的系统性偏差风险。缺乏人类评估的对比或校准来验证自动裁判的可靠性。
- **合成数据的质量上限**: SFT和RL的数据完全来源于模型自身的合成对话。虽然经过了严格筛选，但合成数据的多样性可能低于真实人类对话，存在“模型内卷”的风险，即模型在不断模仿自己生成的有偏分布。
- **9B非思维道对比的不对称性**: 将9B无思考模型的结果与27B思考模型直接比较（以说明后训练优势），虽然论点成立，但其部署场景的最终性能基准（加上延迟要求）并未被完整呈现。
- **伦理风险的潜在性**: 尽管论文从定义上规避了“意识”等问题，并强调了披露义务，但高度拟人化的聊天系统依然存在加深用户情感依赖或被骗取信任的风险，其在情感脆弱场景下的长期影响有待进一步研究。
