## 摘要
本文提出了Chronocooked，一个用于研究强化学习智能体隐式间隔计时能力的强化学习（RL）基准套件。受Overcooked启发，该套件包含需要时间决策的烹饪场景。任务和奖励函数的设计使得时间信息不可观测但对最优性能至关重要。环境被有意保持简单，以便进行受控实验并支持生物合理模型。评估指标旨在暴露RL智能体计时能力的局限性，我们报告了使用非循环、循环和生物合理模型的基线结果。这项工作最终旨在强调，在为人机交互和部署于依赖时间的人类社会而设计的人工智能体中，纳入时间感知和时间处理的必要性。

## Abstract
This paper presents Chronocooked, a reinforcement learning (RL) benchmark suite for studying implicit interval timing in RL agents. Inspired by Overcooked, the suite comprises cooking scenarios that require temporal decision making. The tasks and reward functions are designed such that temporal information is unobserved yet critical for optimal performance. The environment is intentionally kept simple to enable controlled experiments and support biologically plausible models. Evaluation metrics are designed to expose limitations in timing abilities of RL agents, and we report baselines using a non-recurrent, a recurrent, and a biologically plausible model. This work ultimately aims to underscore the need to incorporate time perception and temporal processing in artificial agents designed for human robot interaction and deployment in time dependent human societies.

### 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

- **核心思想**：借鉴心理学中的二分任务（bisection）和固定间隔计时（fixed interval, FI）任务，将其隐式嵌入到简化的 Overcooked 烹饪场景中，使时间成为必须推断的隐藏变量。
- **环境设计**：
  - 基于 Gymnasium 的简化版 Overcooked-AI 环境，为 5×3 或 4×3 网格世界，包含洋葱分配器、烤箱和交付柜台。
  - 智能体需要完成：取洋葱 → 放入烤箱 → 等待烹饪（时间阶段）→ 取出汤 → 交付。
  - 烤箱内部维护一个不可见计时器，与预设目标时长（TD）绑定。计时阶段没有显式状态告知剩余时间；只有达到 TD 后烤箱才变为“ready”状态。
  - 奖励函数不包含任何显式时间信息，时间必须由智能体自行推断。
- **任务类型**：
  - **二分任务**：两个锚定时长 S（短）和 L（长），训练时各占 50%。测试时引入中间时长，智能体需将中间时长分类为“短”或“长”，对应两个交付柜台。奖励 +1 为正确交付，其他为 0。
  - **固定间隔计时任务**：烤箱时长作为固定间隔，提前交互无状态变化，达到 TD 后才可取汤；奖励 +1 为成功交付。折扣因子隐式鼓励尽早交付。
  - **多计时器任务**：在 FI 基础上引入缓冲窗口（TD ± buffer），提前或迟到仅得 0.1 奖励；支持多个 TD 同时训练，通过不同烤箱状态提示当前时长。
  - **双任务**：引入额外奖励汇，要求智能体在计时阶段合理分配时间并及时返回烤箱。
  - **不确定性任务**：提供手动关闭烤箱按钮，烤箱有小概率不会自动变为 ready，需智能体判断何时使用手动按钮。

  - 多计时器容量：不同 TD 数量下的平均奖励与“烤箱关闭时间”变化模式。
  - 分布外（OOD）泛化：训练子集 TD，测试未见过 TD 的行为变化。
- **模型**：
  - 非循环：CNN-MLP。
  - 循环：CNN-LSTM-MLP。
